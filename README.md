# Registration Form

A simple registration form that validates user inputs in real time using JavaScript.

## 🚀 Features

### 👤 Name Validation

* Checks if the Name field is empty
* Displays an error message when left blank

### 📧 Email Validation

* Validates the email format
* Displays an error message for invalid emails

### 🔒 Password Validation

* Ensures the password contains at least 6 characters
* Displays a warning for short passwords

### ✅ Form Validation

* Real-time validation while typing
* Error messages update instantly
* Submit button remains disabled until all fields are valid

## 🛠️ Technologies Used

* HTML5
* JavaScript (Vanilla JS)
